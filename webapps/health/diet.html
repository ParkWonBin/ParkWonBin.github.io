🍚 탄수화물 = 연료. 하지만 너무 많으면 지방이 돼요

탄수화물은 자동차의 휘발유와 같아요. 적당히 넣으면 잘 달리지만, 기름통이 꽉 찬 상태에서 더 넣으면? 기름이 넘쳐서 바닥(뱃살)에 고여요. 특히 주스·음료처럼 마시는 탄수화물이 가장 위험! 소화 과정 없이 바로 혈당 폭발!

✅ DO

밥 먹기 전에 단백질·채소 먼저 → 혈당 천천히 올라감

❌ NOT DO

과일주스로 건강 챙기기 → 섬유질 없는 과당 = 간에 직행

→ Ep.02~Ep.04, Ep.07

🔑 인슐린 = 문지기 아저씨

인슐린은 피 속 설탕을 세포 안으로 넣어주는 문지기예요. 그런데 이 문지기가 일하는 동안에는 지방 창고 문을 잠가버려요! 그래서 아무리 운동해도 인슐린이 높으면 지방이 안 타요.

✅ DO

12~16시간 공복 → 문지기 퇴근 → 지방 창고 열림!

❌ NOT DO

달달한 간식 조금씩 자주 → 문지기가 24시간 근무 → 지방 절대 안 빠짐

→ Ep.05, Ep.06

🥩 단백질 = 벽돌 + 보일러

단백질은 근육을 만드는 벽돌이면서, 소화할 때 열을 내는 보일러예요. 100칼로리를 먹으면 30칼로리는 소화 과정에서 그냥 사라져요! (= TEF) 호르몬, 면역세포, 효소도 다 단백질로 만들어져요.

✅ DO

매끼 손바닥 크기 단백질 + 채소 먼저

❌ NOT DO

다이어트 때 단백질 부족 → 근육 빠짐 → 대사 뚝 → 요요

→ Ep.12, Ep.13

🫒 좋은 지방을 먹어야 나쁜 지방이 타요

지방을 안 먹으면 몸이 "지방 아껴야 해!"라고 판단해서 오히려 지방을 안 태워요. 좋은 지방을 먹으면 몸이 지방 태우는 법을 배워요! 이걸 지방 적응이라고 해요.

✅ DO

올리브유, 아보카도, 등푸른 생선 → 좋은 기름

❌ NOT DO

대두유·옥수수유(종자유), 마가린, 재사용 튀김유 → 나쁜 기름

→ Ep.14, Ep.15

🫗 제로 음료 = 뇌를 속이는 사기꾼

혀가 단맛을 느끼면 뇌가 "설탕 온다!" → 인슐린을 미리 분비해요. 그런데 진짜 설탕이 안 오면? 혈당 떨어짐 → 가짜 배고픔 → 과식!

✅ DO

물, 탄산수, 차 → 깔끔하게

❌ NOT DO

"칼로리 0이니까 마음껏" → 뇌 보상 회로가 진짜 당분을 더 갈망

→ Ep.22

📖 에피소드별 상세

Ep.02~Ep.04 탄수화물 — 연료인가, 독인가

핵심 원리

  • 탄수화물 = 연료: 뇌와 근육의 폭발적 에너지원이지만, 현대인의 활동량에 비해 과잉 공급되고 있다 Ep.03
  • 형태와 무관하게 혈당을 올리는 모든 것이 탄수화물: 밥·빵·면뿐 아니라 양념 소스, 과일주스, 뿌리채소, 견과류의 당분까지 포함 Ep.02
  • 액체 탄수화물이 가장 위험: 위 통과 시간이 거의 제로 → 혈당 수직 상승 → 인슐린 폭발 Ep.04
  • 과당(Fructose)은 간에서만 처리: 간 처리 용량 초과 시 즉시 내장지방·지방간으로 전환 Ep.04

✅ DO

실천법근거
밥 대신 단백질·채소를 먼저 먹기식사 순서만 바꿔도 인슐린 분비 20~30% 감소 Ep.07
식품 성분표에서 설탕·액상과당·감미료 확인숨은 탄수화물이 다이어트 실패의 주범 Ep.02
갈증 시 물·차·탄산수 선택액체 칼로리는 포만감 중추를 자극하지 못함 Ep.04
탄수화물은 '씹어 먹기'고체는 소화 과정에서 혈당이 서서히 오름 Ep.04
자연식(비가공) 탄수화물 선택섬유질이 혈당 상승 속도를 늦춤 Ep.20

❌ NOT DO

금지법이유 / 폐해
야식으로 탄수화물 섭취밤에는 활동량 없어 소모 불가 → 지방 저장 + 당독소(AGEs) 생성 Ep.03
과일주스로 건강 챙기기과당이 간에 직접 부하, 섬유질은 제거됨 → 지방간 + 인슐린 저항성 Ep.04
운동 후 이온음료·에너지음료숨은 당분이 지방 저장 스위치를 켬 → 운동 효과 상쇄 Ep.04
달달한 간식을 '조금씩 자주'칼로리는 낮아도 인슐린 하루 종일 높게 유지 → 지방 분해 완전 차단 → 요요 Ep.05

Ep.05~Ep.06 인슐린 — 마스터 스위치

핵심 원리

  • 인슐린 = 지방 저장 호르몬: 혈액 속 에너지를 세포에 넣는 열쇠 역할 Ep.05
  • 인슐린이 높은 동안 = 지방 분해 완전 차단: 세포 문을 안에서 잠그는 것과 같음 Ep.05
  • 인슐린 저항성: 세포가 인슐린에 둔감해지면 → 더 많은 인슐린 분비 → 악순환 Ep.05
  • 모든 영양소 중 지방이 인슐린을 가장 적게 자극 Ep.14
"아무리 적게 먹고 열심히 뛰어도, 혈액 속에 인슐린이 가득하다면 당신의 몸은 지방을 태울 생각조차 하지 않는다. 이건 의지의 문제가 아니라 생물학적 법칙이다." — Benjamin Bikman, Why We Get Sick

✅ DO

실천법효과
최소 12시간 공복 유지 (이상적: 14~16시간)인슐린이 충분히 낮아져야 지방 창고의 문이 열림 Ep.06
정제 탄수화물·액체당·달달한 간식 끊기인슐린 폭발 원인 제거 Ep.05
운동 강도 높이기 전에 인슐린 스위치부터 끄기호르몬 조절이 운동보다 선행 Ep.05

❌ NOT DO

금지법결과
밤 11시 야식 → 아침 7시 식사 (공복 8시간)공복 시간 부족 → 인슐린 휴식 불가 Ep.06
칼로리만 줄이고 탄수화물 종류는 무시인슐린 높은 상태에서 근육만 소모 → 기초대사량↓ Ep.05

Ep.12~Ep.13 단백질 — 벽돌이자 부스터

핵심 원리

  • TEF(식사성 발열 효과): 단백질 100kcal 중 ~30kcal는 소화에서 소멸. 탄수화물 5~10%, 지방 0~3% Ep.12
  • 호르몬 원료: 인슐린, 성장호르몬, 세로토닌, 도파민 모두 아미노산 필요 Ep.13
  • 면역·소화 효소의 재료: 항체, 소화 효소 역시 전부 단백질 Ep.13
  • 포만감 호르몬 촉진: PYY·GLP-1 분비↑, 그렐린↓ Ep.12

✅ DO

실천법근거
매끼 손바닥 크기 단백질 먼저 챙기기TEF + 포만감 + 기아모드 방지 Ep.12
한 번에 몰아먹지 말고 매끼 나누어 섭취아미노산 저장 창고가 크지 않음 Ep.13
채소와 함께 먹기금상첨화 조합 Ep.12

❌ NOT DO

금지법폐해
다이어트 시 단백질 부족근육 분해 → 기초대사량↓ → 요요 Ep.08, Ep.12
단백질 부족 상태에서 운동면역력 저하, 머리카락 가늘어짐, 피부 푸석 Ep.13

Ep.14~Ep.15 지방 — 불쏘시개이자 호르몬 원료

핵심 원리

  • 지방 적응(Fat-Adaptation): 양질의 지방을 넣어줘야 몸이 지방을 연료로 쓰는 법을 학습 Ep.14
  • 지방은 인슐린을 거의 자극하지 않는 유일한 에너지원 → HSL(지방 분해 효소) 활성화 Ep.14
  • 성호르몬(테스토스테론, 에스트로겐)과 세포막은 콜레스테롤/지방으로 구성 Ep.14
  • 지방을 극도로 제한하면 호르몬 불균형 → 기아 모드 Ep.14

올리브유 가열 관련 Ep.15.5

  • 엑스트라 버진 올리브유는 발연점 이하(180°C 이하)에서 안정적
  • 올레산(단일불포화지방산)은 열에 강하고 항산화 폴리페놀이 산화를 방어
  • 발연점을 넘기면 유해물질(알데히드) 생성 → 저온~중온 조리 권장

산패된 기름의 위험 Ep.15

  • 오메가6 지방산(리놀레산) 과잉 → 아라키돈산 → 염증 촉진 사이토카인 분비
  • 종자유(대두유·옥수수유)는 정제 과정에서 이미 산패 시작
  • 만성 염증 → 인슐린 저항성 → 지방 축적 악순환

Ep.21 소금의 재평가

핵심 원리

  • 나트륨은 전해질 균형, 신경 전달, 근수축에 필수
  • 문제는 '소금 자체'가 아니라 가공식품 속 정제 나트륨 + 설탕 조합
  • 양질의 천일염·암염을 적절히 섭취하면 오히려 대사 부스터 역할

Ep.22 제로 음료의 함정

핵심 원리

  • 세팔릭 인슐린 반응(CPIR): 단맛을 혀가 감지하면 뇌가 "당분이 온다"고 예측 → 인슐린 선제 분비
  • 실제 당분이 안 들어오면 → 혈당 강하 → 가짜 배고픔 → 과식 유발
  • 장내 미생물 교란 + 단맛 중독 지속

❌ NOT DO

금지법이유

Ep.08 기아 모드와 대사 저하

핵심 원리

  • 극도의 칼로리 제한 → 몸이 "기근"으로 판단 → 적응 열생산(Adaptive Thermogenesis) 발동
  • 기초대사량 강제 하락 + 근육 분해 + 지방 보존 → "적게 먹어도 안 빠지는" 상태
  • 이후 정상 식사로 돌아가면 → 낮아진 대사량으로 칼로리 잉여 → 요요

✅ 기아 모드 방지법

Ep.11 📐 1단계 총정리 공식

살이 안 찌는 체질 = 인슐린 낮은 상태 + 대사 유연성 높은 상태

3가지 핵심

  1. 인슐린 마스터키 관리 → 액체 탄수화물·정제당 끊기
  2. 입 쉬게 하기 → 최소 12시간 공복 (14~16시간 이상적)
  3. 숫자의 함정 탈출 → 기초대사량 숫자 < 깨끗한 식단 + 근육 운동 + 대사 유연성
