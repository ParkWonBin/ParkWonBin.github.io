😴 잠이 최고의 보충제예요

잠자는 동안 성장호르몬(= 몸 고치는 호르몬)이 쏟아져 나와요. 깊은 잠을 자면 에너지의 60~70%를 지방에서 가져와요. 자면서 살이 빠지는 거예요! 반대로 잠 못 자고 운동하면? 그건 운동이 아니라 노동이에요. 근육은 빠지고 지방만 남아요.

✅ DO

매일 7~8시간 수면 확보 (운동보다 우선!)

❌ NOT DO

5시간 자고 새벽 운동 → 코르티솔(= 스트레스 호르몬) 폭발

→ Ep.27 Ep.35

☀️ 아침 햇빛 = 몸의 시계 맞추기

우리 몸 안에 24시간 시계가 있어요. 이걸 서카디안 리듬이라고 해요. 아침에 햇빛을 보면 뇌가 "아, 낮이구나!" 하고 시계를 맞춰요. 시계가 맞으면: 낮엔 에너지 활활, 밤엔 꿀잠. 시계가 틀어지면: 살 찌고 잠 못 자요.

✅ DO

기상 후 30분 이내 햇빛 10분 + 저녁엔 조명 어둡게

❌ NOT DO

밤에 스마트폰 → 멜라토닌(= 수면 호르몬) 분비 차단

→ Ep.36 Ep.66

😰 스트레스가 뱃살을 만들어요

스트레스를 받으면 코르티솔(= 스트레스 호르몬)이 나와요. 이 호르몬은 지방을 배 안쪽(내장지방)에 쌓아요. 뱃살의 진짜 원인! 복근 운동 100개보다 스트레스 줄이기가 뱃살 빼기에 더 효과적이에요.

✅ DO

산책, 명상, 4-7-8 호흡법 → 코르티솔 낮추기

❌ NOT DO

스트레스 받으면 달달한 음식 → 코르티솔 + 인슐린 = 더 뚱뚱

→ Ep.34 Ep.37

🫁 코로 숨 쉬세요!

코로 숨 쉬면 NO(= 혈관을 넓히는 좋은 기체)가 만들어져요. 입으로만 숨 쉬면 이게 안 만들어지고, 오히려 산소 전달이 나빠져요. 호흡 하나 바꾸는 것만으로도 스트레스가 확 줄어요!

✅ DO

4-7-8 호흡 (코로 4초 들이쉬고, 7초 참고, 8초 내쉬기)

❌ NOT DO

만성적 입호흡 → 구강 건조, 면역 저하, 수면 무호흡 악화

→ Ep.42

🧠 뇌도 세탁기가 필요해요

깊은 잠 잘 때 뇌세포가 60% 줄어들면서 뇌 속 찌꺼기를 씻어내요. 이걸 글림파틱 시스템(= 뇌의 세탁기)이라고 해요. 8시간 누워 있어도 얕은 잠만 자면 세탁기가 안 돌아가요. 중요한 건 깊이!

✅ DO

취침 90분 전 따뜻한 샤워 + 침실 18~20°C + 같은 시간 기상

❌ NOT DO

자기 전 SNS/유튜브 → 뇌가 각성 → 깊은 잠 불가

→ Ep.66

📖 에피소드별 상세

Ep.27 잠 못 자면 운동도 '노동'

  • 수면 부채(Sleep Debt): 누적된 수면 부족은 보상 수면으로 갚기 어려움
  • 수면 부족 시: 코르티솔↑ + 성장호르몬↓ + 테스토스테론↓
  • 잠 못 자고 새벽 운동 = 노동: 근합성 대신 근분해, 지방 연소 대신 지방 저장

✅ DO

수면 7~8시간 확보가 운동보다 선행. 수면 부족하면 운동 강도 낮추거나 휴식. "수면은 최고의 보충제"

❌ NOT DO

5시간 자고 새벽 4시 고강도 운동 → 코르티솔 폭발 → 근손실. "잠을 줄여서 운동 시간 확보" → 역효과. 수면 부채를 주말 몰아자기로 해결

Ep.34 뱃살의 원인이 스트레스라면

  • 코르티솔: 만성 스트레스 시 내장지방(뱃살) 선택적 축적
  • 내장지방 세포에는 코르티솔 수용체가 가장 많음 → "스트레스 = 뱃살"은 생리학적 사실
  • HPA축(시상하부-뇌하수체-부신) 과활성 → 코르티솔 24시간 고농도
영역만성 코르티솔의 폐해
체형내장지방(뱃살) 선택적 축적
근육이화작용 촉진 → 근육 분해
수면각성 상태 유지 → 불면
면역면역 억제 → 감염 취약
대사인슐린 저항성 유발 → 혈당 불안정
정신불안, 우울, 감정 기복

✅ DO

스트레스 원인 파악 + 관리 전략 (운동, 산책, 명상, 사회적 연결). 코르티솔을 낮추는 것이 뱃살 감량의 선결 조건

❌ NOT DO

스트레스를 음식(달달한 것)으로 해소 → 코르티솔 + 인슐린 폭발 → 악순환. 뱃살에 복근 운동만 → 스트레스 원인 해결 안 하면 무의미

Ep.35 잠든 사이 지방은 탄다

  • 성장호르몬(GH): 깊은 수면(N3) 중 하루 분비량의 70~80% 방출. 역할: 지방 분해 + 근육 합성 + 세포 재생
  • 수면 중 에너지원의 60~70%가 지방: "잠자면서 살 빠지는" 상태는 실재
  • 렙틴↑ + 그렐린↓: 수면 충분 → 식욕 자연 억제

✅ DO

7~8시간 깊은 수면 확보. 취침 전 당분 섭취 금지 → 인슐린이 성장호르몬 억제. 어둡고 시원한 침실 (18~20°C)

❌ NOT DO

야식 → 바로 취침: 인슐린 상승 → 성장호르몬 차단 → 지방 연소 불가. 취침 직전 밝은 조명/스마트폰 → 멜라토닌 억제

Ep.36 생체시계와 다이어트: 태양이 결정한다

  • 서카디안 리듬: 24시간 생체 시계
  • SCN(시교차상핵): 눈으로 들어온 광신호를 받아 마스터 시계 동기화
  • 아침 햇빛 → 코르티솔 자연 상승(각성) + 멜라토닌 억제
  • 저녁 어둠 → 멜라토닌 분비 시작 → 수면 준비
  • 2017년 노벨 생리의학상: 서카디안 리듬 연구
시간대최적 활동이유
기상 후 30분햇빛 노출SCN 리셋, 코르티솔 아침 피크 정상화
오전~오후고강도 운동체온·반응 속도·근력 최고점
저녁 7시 이후식사 마무리공복 → 수면 중 지방 연소 최적화
취침 2시간 전전자기기 차단멜라토닌 분비 보호

✅ DO

기상 후 30분 이내 자연광 10분. 식사 시간 일정하게 → 말초 시계(간, 위, 장) 동기화. 저녁 식사 후 12~16시간 공복

❌ NOT DO

밤에 강한 조명·블루라이트 → 서카디안 리듬 파괴. 불규칙한 식사·수면 시간 → 생체시계 혼란 → 대사 저하

Ep.37 24시간 전투 모드: 교감신경 과활성

  • 교감신경(전투): 심박↑, 혈압↑, 코르티솔↑, 소화 억제
  • 부교감신경(회복): 심박↓, 소화 촉진, 세포 수리, 면역 활성
  • 현대인: 교감신경 과활성 → 부교감신경 억제 → 회복 불가 상태

다미주신경 이론 (Polyvagal Theory)

  • 미주신경(Vagus Nerve): 부교감신경의 핵심. 뇌-장-심장 연결
  • 미주신경 톤: HRV(심박변이도)로 측정 → 높을수록 회복 능력 우수

✅ 부교감 활성화 3가지

  1. 호흡법: 4-7-8 호흡 (들숨 4초, 참기 7초, 날숨 8초) → 미주신경 자극
  2. 자연 속 산책: 부교감신경 활성 + 세로토닌 증가
  3. 사회적 연결: 긍정적 관계 → 옥시토신 분비 → 코르티솔 억제

❌ NOT DO

잠들기 전까지 업무 → 교감신경 과활성 상태로 취침. 격한 감정 후 바로 고강도 운동 → 코르티솔 + 운동 스트레스 중첩. 미주신경의 80%는 복부 장기 연결 → 장 건강 무시 = 부교감 기능 저하

Ep.42 호흡의 생리학: 10분의 비밀

  • 보어 효과: CO2 ↑ → 헤모글로빈이 산소를 더 잘 방출
  • 산화질소(NO): 코호흡 시 부비강에서 생성 → 혈관 확장 → 혈류 개선
코호흡 ✅입호흡 ❌
NO 생성 → 혈관 확장NO 생성 없음
공기 여과·가습·가온건조한 공기 직접 유입
CO2 적절 유지 → 산소 전달↑CO2 과다 배출 → 산소 전달↓
부교감신경 활성화교감신경 자극 (과호흡)

✅ DO

일상에서 코호흡 습관화. 4-7-8 호흡법: 부교감 활성 → 스트레스 감소. 박스 호흡 (4-4-4-4): 집중력 향상 + 자율신경 조절

❌ NOT DO

만성적 입호흡 → 구강 건조, 면역 저하, 수면 무호흡 악화. 과호흡 습관 → CO2 부족 → 현기증, 불안 증가

Ep.43 뇌가 지쳤을 때: 중추 피로

  • 중추 피로(Central Fatigue): 근육이 아니라 뇌가 "그만!" 신호
  • 기전: 장시간 운동/스트레스 → 혈중 트립토판↑ → 뇌 세로토닌 과잉 → 졸림·무기력
  • 트립토판 vs BCAA 경쟁: BCAA가 혈중에 풍부하면 트립토판의 뇌 진입 차단
  • 글루타민 고갈: 과도한 운동 → 글루타민 소모 → 면역 저하 + 뇌 피로

✅ DO

BCAA/EAA 보충 (장시간 운동 시) → 중추 피로 지연. 운동 강도 주기화 → 만성 중추 피로 방지. 자연 속 산책, 명상 → DMN(디폴트 모드 네트워크) 리셋

❌ NOT DO

"피곤한 건 의지력 부족" → 중추 피로는 생리학적 현상. 뇌 피로 상태에서 고강도 운동 → 과훈련 촉진

Newsholme & Blomstrand (2006)

Ep.66 기절 수면법: 글림파틱 시스템

  • 글림파틱 시스템: 수면 중 뇌의 노폐물 제거 시스템. 깊은 수면 시 뇌세포 60% 수축 → 뇌척수액이 노폐물(베타-아밀로이드 등) 세척
  • 8시간 누워 있어도 얕은 수면만 반복하면 뇌 세척 불가
  • 핵심: 수면 '시간'보다 수면 '깊이'
  • 수면 1주기: 약 90분 (N1 → N2 → N3 → REM) × 4~5사이클
기절 수면법효과
취침 90분 전 따뜻한 물 샤워/목욕심부 체온 상승 후 하강 → 깊은 수면 유도
침실 18~20°C심부 체온 하강 촉진
취침 3시간 전 카페인 차단N3 단계 방해 제거
매일 같은 시간 기상서카디안 리듬 안정화

❌ NOT DO

취침 직전 SNS·유튜브 → 도파민 각성 → 깊은 수면 방해. 알코올로 수면 유도 → N3/REM 단계 억제 → 글림파틱 작동 불가

Xie et al. (2013): "수면은 단순한 휴식이 아니라, 뇌를 씻는 시간이다."
Murphy & Campbell (1997): 심부 체온 하강이 수면 개시의 생리적 트리거
